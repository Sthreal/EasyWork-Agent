# 通用办公自动化 Agent 技术 PRD（V0.3 可直接用版）

> 核心 = 用户原文，未删改。
> 所有标「默认」的都是常见做法，不是定死的，想改随时说。
> 风险均为作者推测。

---

## 30秒版（背这个）

员工说人话 → Agent 拆成几步 → 该调工具就调（邮件/日历/表格）→ 删除/覆盖/发送/外发要先点确认 → 做完给反馈。

## 核心需求（用户原文，不改）

> 我想做一个通用办公自动化 Agent。
> 员工自然语言输入然后 Agent 拆解意图，拆解为多个子任务，
> 如果需要调用工具则调用，成功执行后给出反馈，高危动作需要员工确认。

## P0（第一版必须有）

| # | 功能 | 说明 |
|---|------|------|
| P0-1 | 自然语言输入 | 员工输入任务 |
| P0-2 | 意图拆解 | 拆成多个子任务 |
| P0-3 | 反问澄清 | 没听懂就反问（已确认） |
| P0-4 | 工具调用 | 邮件/日历/表格（已确认） |
| P0-5 | 高危确认 | 删除/覆盖/发送/外发 → 页面按钮确认，超时挂起（已确认） |
| P0-6 | 执行反馈 | 做完给结果反馈 |

## 默认设定（可改，不影响P0）

| 事项 | 默认做法 |
|------|----------|
| 登录 | 简单账号密码登录（默认） |
| 权限 | 先不限制，登录都能用（默认）；按角色限权限放 P1 |
| 邮件 | 能读、能发（默认） |
| 日历 | 能建、能改自己的日程（默认） |
| 表格 | 能读、能写自己可见的文件，写前给变更预览（默认） |
| 反馈 | 任务全部结束后给汇总；失败也明确说失败原因（默认） |
| 部分失败 | 其余继续执行，最后汇总哪些成功哪些失败（默认） |
| 部署 | 先内网/单机部署，用境内大模型（默认） |
| 规模 | 先小范围内测，不用考虑高并发（默认） |
| 审计 | 先记简单操作日志（默认）；完整审计放 P1 |

## P1（以后做，建议）

权限角色、任务历史/审计、失败重试、进度逐步反馈、挂起任务提醒、定时批量任务、更多工具接入。

## 非目标

不做 IM 集成；不做无人值守全自动；不做跨部门复杂工作流；不做模型训练。

## 风险（推测）

| 风险 | 程度 | 对策（建议） |
|------|------|--------------|
| 工具误操作（删错/发错） | 高 | 高危必确认，先测试环境演练 |
| 拆错意图，做错事 | 高 | 执行前展示子任务清单，重要任务可先看再执行 |
| 假报成功（实际没执行） | 高 | 以工具真实返回为准，不编结果 |
| 越权/泄露 | 中 | 最小权限，日志留痕 |
| 表格被误写 | 中 | 写前预览变更 |

## 技术结构（默认方案）

员工端 → Agent（拆解+反问）→ 工具层（邮件/日历/表格）→ 高危确认闸门 → 结果反馈
