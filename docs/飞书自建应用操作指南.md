# 飞书自建应用操作指南（前置 P1）

> 先搞清楚：飞书「群」≠ 企业。群只是聊天组织，没有开发者后台，**不能在群里建应用**。
> 应用必须挂在「企业（租户）」下。你有两条路：**测试企业（自己搞定，免审批）** / **正式企业（要管理员审批）**。

---

## 方案 A：测试企业（推荐先做，开发联调用，自己就能搞定）

1. 打开 **https://open.feishu.cn**，用你的飞书账号登录（普通成员即可）
2. 开发者后台 → **创建企业自建应用** → 填应用名称、描述、图标 → 创建
3. 应用详情左侧「**测试企业和人员**」→ 右上角「**创建测试企业**」→ 填测试企业名称 + 你的手机号 + 验证码 → 确认
4. 在测试企业列表操作栏点「**关联应用**」，把刚建的应用关联到测试企业
5. 「权限管理」→ 添加 3 个权限：
   | 权限 | 用途 |
   |------|------|
   | `calendar:calendar:readonly` | 读日历/日程（M2 日历工具） |
   | `calendar:calendar` | 建/改/删日程（M2 日历工具） |
   | 用户信息只读（如 `contact:user.base:readonly`，以开放平台当前名称为准） | 登录（M1-3） |
6. 「安全设置」→ 重定向 URL 填：`http://localhost:8000/api/v1/auth/callback`
7. 开启网页应用 **OAuth 登录**
8. 复制 **App ID / App Secret**（Secret 只显示一次）→ 填进项目 `.env`

**测试企业的好处**：权限直接生效、配置变更免审核，开发调试最快。
**注意**：测试企业是独立测试环境，不是你们真实企业；正式给员工用仍需走方案 B。

---

## 方案 B：正式企业（上线/真实员工用，需管理员审批）

1. 打开 **https://open.feishu.cn**，用你的工作飞书账号登录
2. 开发者后台 → 创建企业自建应用 → 填名称 → 创建
3. 复制 App ID / App Secret
4. 权限管理 → 添加上面 3 个权限
5. 安全设置 → 重定向 URL（开发：localhost；正式：正式域名 + `/api/v1/auth/callback`）
6. 开启 OAuth 登录
7. 版本管理与发布 → 创建版本 → **可用范围选「指定成员」**（内测名单 ≤50 人）→ 提交发布
8. **等待企业管理员审批**（1~3 天）
9. 审批通过后，把 App ID / App Secret / Redirect URI 填进 `.env`

如果自己不是管理员：把本指南发给管理员，管理员只需做「审批」相关步骤。

## 补充：令牌自动刷新（M1-4）

- 授权 URL 已带 scope=offline_access，用于换取 refresh_token 实现自动刷新
- 若刷新不生效，检查：应用「权限管理」是否开通 offline_access；「安全设置」是否开启「刷新 user_access_token」开关
