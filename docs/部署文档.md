# 部署文档

> 环境：Python 3.11+ / Node 18+ / SQLite（生产可换 PostgreSQL）
> 依赖外部：飞书开放平台应用、QQ 邮箱（IMAP/SMTP 授权码）、境内大模型（DeepSeek 等）

---

## 1. 首次安装

```bash
# 后端依赖
cd "D:\download new\ai_coding\Cool note\office-agent"
pip install -r requirements.txt

# 前端依赖
cd frontend
npm install
```

## 2. 配置 .env

复制 `.env.example` 为 `.env`（.env 已进 .gitignore，不会提交）：

| 配置 | 说明 |
|------|------|
| FEISHU_APP_ID / FEISHU_APP_SECRET | 飞书开放平台自建应用凭证 |
| FEISHU_REDIRECT_URI | 回调地址，必须与飞书后台「安全设置」完全一致 |
| QQ_MAIL_ADDRESS / QQ_MAIL_AUTH_CODE | QQ 邮箱 + IMAP/SMTP 授权码（发件邮箱） |
| LLM_API_KEY / LLM_BASE_URL / LLM_MODEL | 大模型（OpenAI 兼容），示例见 .env.example |
| DATABASE_URL | 默认 SQLite：`sqlite:///./office_agent.db` |
| FRONTEND_URL | 登录成功后前端跳转地址，默认 `http://localhost:5173` |
| SHEETS_DATA_DIR | 表格工具允许操作的目录，默认 `D:\download new\ai_coding\Cool note\Excel数据` |

## 3. 初始化数据库

```bash
python scripts/init_db.py
# 会创建：users / feishu_tokens / tasks / task_items / confirmations
```

## 4. 启动

### 开发环境

```bash
# 终端1：后端（只监听代码目录，测试写日志不会触发重启）
python -m uvicorn backend.main:app --port 8001 --reload --reload-dir backend --reload-dir config

# 终端2：前端
cd frontend
npm run dev        # http://localhost:5173（/api 自动代理到 8001）
```

### 生产环境

```bash
# 后端（不带 --reload）
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8001

# 前端构建
cd frontend
npm run build      # 产物在 frontend/dist
```

前端 dist 由 Nginx/静态托管提供，`/api` 反向代理到后端 8001：

```nginx
server {
    listen 80;
    server_name your.domain.com;
    root /path/to/frontend/dist;
    location / {
        try_files $uri $uri/ /index.html;
    }
    location /api/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 5. 飞书配置（首次必须）

1. 开发者后台 → 应用「安全设置」→ 重定向 URL 填 `http://localhost:8001/api/v1/auth/callback`（正式环境换域名）
2. 权限管理开通：`calendar:calendar:readonly`、`calendar:calendar`、用户信息只读、`offline_access`（刷新令牌）
3. 安全设置开启「刷新 user_access_token」开关
4. 版本发布 → 可用范围选择使用人员 → 管理员审批

> 详细步骤见《飞书自建应用操作指南.md》。

| 操作 | 命令/位置 |
|------|-----------|
| 查看日志 | `logs/app.log`（请求 + 错误堆栈） |

| 跑测试 | `python -m pytest tests -q` |

## 7. 常见问题

| 问题 | 处理 |
|------|------|
| 登录失败/回跳无 code | 重定向 URL 与飞书后台不一致；或授权码过期，重新登录 |
| token 过期报飞书错误 | 用户重新飞书登录一次（自动刷新链断裂时） |
| 500 且日志无记录 | 前端代理连不上后端 → 检查 8001 是否在跑 |
| 端口被占用 | 换端口：后端 `--port`，前端 `vite.config.js` 的 proxy 同步改 |
| 邮件发不出 | 检查 QQ 邮箱 IMAP/SMTP 是否开启、授权码是否正确 |
| 数据库锁 | 已启用 WAL + busy_timeout；仍出现则检查是否多实例同时写 |

## 8. 生产注意事项（建议）

- 用 HTTPS（登录授权要求正式环境 https）
- 数据库 SQLite 适合小规模；正式多人可换 PostgreSQL（改 `DATABASE_URL`，代码已兼容）
- 定期备份 `office_agent.db` 和 `Excel数据` 目录
- 日志按天滚动保留 7 天（config/logging.py 已配置）
